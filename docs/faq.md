# 常见问题

## 需要 pip 安装什么吗？

不需要。本工具零依赖，只用 Python 标准库。凡是让你先 pip install 的同类脚本都是别的实现。

## 用哪个命令运行？

- macOS / Linux：`python3 get_superpwd.py`
- Windows：`py get_superpwd.py`（没有 py 启动器时用 `python get_superpwd.py`）
- Python 版本 3.7 ~ 3.13 都可以。用 `--self-test` 可以先离线验证本机环境。

## 提示光猫 8080 连不上怎么办？

按脚本的局域网检查提醒逐项看：

1. 电脑是否连在这台光猫 / 同一台路由器下的网络（不要连手机热点、访客 WiFi，先关 VPN）
2. IP 是否输对（直接回车是默认 192.168.1.1，你家如果改过网段要输实际地址）
3. 光猫是否开机、网线 / WiFi 是否正常

本机和光猫不在同一网段不一定是问题：光猫在路由器上游时（如光猫 192.168.1.1、电脑 192.168.2.x），跨网段经路由可达是正常拓扑，以端口可达为准。

## MAC 读不到怎么办？

脚本会转到手动输入：把机身贴纸上的 MAC 输进去，带横杠（D0-69-FF-…）或 12 位连写都可以。MAC 是派生加密密钥的种子，输错了后面全部解不开，请仔细核对。

## Telnet 密码试哪组？

脚本打印的是按你本机 MAC 算出的带后缀那组，优先用它。个别机型是不带后缀的固定值。注意：连错 3 次会锁定约 300 秒，最多试有依据的两组，错了就停下来等，不要猜。

## macOS 上敲 telnet 命令报 command not found？

苹果已从系统里删除 telnet 客户端，与光猫无关。用系统 Python 自带的客户端代替（Python 3.12 及以下）：`python3 -m telnetlib 192.168.1.1`。先测端口可以用 `nc -vz 192.168.1.1 23`。

## Windows 上怎么测 23 端口？

PowerShell 里运行 `Test-NetConnection 192.168.1.1 -Port 23`，看 `TcpTestSucceeded` 是 True 还是 False。

## 运行这个脚本会影响上网吗？

只读模式不会：它只读取 MAC、设备信息和账号密码，不改配置、不重启。选择开启 / 关闭 Telnet 时只动 Telnet 服务开关，不碰拨号、VLAN、WiFi 等上网配置。

## 其它型号的天翼网关能用吗？

只有烽火 HG5585F 已实测。华为、中兴代工的机型接口不同，不能用。同为烽火同平台的机型可以一试，结果欢迎反馈到 Issue（注意脱敏）。
